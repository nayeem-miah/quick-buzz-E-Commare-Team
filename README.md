# **Quick Buzz – Modern E-Commerce Platform for Bangladesh**

A scalable, secure, and high-performance e-commerce platform designed for the Bangladeshi market, built with the MERN stack and modern tools. The project provides a seamless shopping experience for customers along with powerful dashboards for vendors and admins.

# ⭐ **Core Features**

## 👤 **User Features**

- Email / Google Login (Firebase Authentication)
- Advanced Search, Filters, Categories
- Order Tracking with real-time updates
- Secure checkout via SSLCommerz

## 🛍️ **Vendor Features**

- Vendor Dashboard to manage products
- Add / Edit / Delete products
- Sales analytics and performance tracking
- Secure vendor authentication

## 🛡️ **Admin Features**

- Admin Dashboard with global controls
- Manage users, vendors, and products
- Vendor approval system
- Handle orders, refunds, and disputes

# ⚙️ **Installation & Setup**

## **📌 Backend Setup**

```bash
git clone https://github.com/nayeem-miah/quick-buzz-E-Commare-Team.git
cd server
npm install
```

Create a `.env` file:

```
MONGO_URI=your_mongo_connection_string
JWT_SECRET=your_jwt_secret
PORT=3000

STORE_ID=your_ssl_store_id
STORE_PASS=your_ssl_store_pass

NODE_ENV=development
```

Start server:

```bash
npm run dev
```
